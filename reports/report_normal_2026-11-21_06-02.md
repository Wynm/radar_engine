### 1. التقييم وحقيقة الأداة (8.5 / 10)
* **ما تفعله فعلياً:** مهارة وظيفية (Agent Skill / Claude Plugin) مدعومة بسكريبتات Python لمعالجة وفحص ملفات SVG. تُجبر النماذج اللغوية على الكشف عن خيارها الأول والترديدي التقليدي (النمطي) في الأعمال الإبداعية، ثم الانتقال الصارم عنه لإنتاج مخرجات إبداعية فريدة غير مكررة.
* **الجاهزية:** جاهزة للاستخدام المباشر كـ Skill داخل Claude أو وكلاء الذكاء الاصطناعي، ومزودة برزم معالجة برمجية جاهزة للإنتاج.

### 2. المجال والفئة المستهدفة
* **المجال:** الذكاء الاصطناعي التوليدي، التصميم البرمجي (Generative Design)، وأتمتة الهويات البصرية.
* **الفئة المستهدفة:** المصممون، وكالات التسويق والهوية البصرية، مطورو وكلاء الذكاء الاصطناعي (AI Agent Developers)، ومصممو واجهات المستخدم (UI/UX).

### 3. الاستغلال الربحي المباشر
* **Micro-SaaS:** بناء أداة توليد شعارات وبوسترات SVG فريدة تضمن عدم التكرار النمطي المنتشر في أدوات الذكاء الاصطناعي الحالية.
* **خدمة لعملاء (Agency):** تقديم خدمات تصميم واجهات وهويات بصرية فائقة السرعة ولكن بطابع بشري غير متوقع، وبيعه بأسعار وكالات كاملة.
* **خفض التكلفة:** تقليل الجولات التكرارية (Iterative Loops) المحبطة مع الذكاء الاصطناعي للوصول إلى تصميم فريد غير تقليدي.

### 4. اختصار مدة العمل
* **المهمة الملقاة:** تلغي عمليات العصف الذهني اليدوية والتعديلات المتكررة لاستبعاد التصاميم والأفكار المستهلكة (Clichés)، وتلغي الفحص اليدوي لملفات SVG والتعديل البصري عليها.
* **الوقت المقتطع:** تختصر مرحلة الأفكار الأولية والنماذج الأولية من 3-5 ساعات إلى أسرع من 10 دقائق (توفير أكثر من 85% من الوقت).

### 5. الاستخدام العملي والحياتي
* **سيناريو يومي:** عند طلب تصميم ملصق إعلاني لحملة تسويقية بصيغة SVG؛ يحسب الوكيل الخيار التقليدي الأول (مثلاً: خلفية زرقاء مع عناصر دائرية وسطية)، يرفضه آلياً بناءً على قواعد المهارة، ثم ينشئ تصميماً معقداً وفريداً ويتحقق من جودته برمجياً عبر `scripts/check.py` ويضيف طابعاً يدوياً عبر `scripts/rough.py`.

### 6. خطوات التشغيل الفورية
1. **استنساب المستودع وتثبيت الملحقات:**
   ```bash
   git clone https://github.com/mankidev/antialgorithm.git
   cd antialgorithm
   pip install numpy pillow
   ```
2. **دمج المهارة (Skill):** ربط مجلد `.claude-plugin` أو نسخ محتوى `SKILL.md` وتضمينه في تعليمات النظام (System Prompt) لـ Claude أو الوكيل الخاص بك.
3. **التشغيل واختبار السكريبتات:** استخدام سكريبت التحقق من SVG مباشرة بعد توليد التصاميم:
   ```bash
   python scripts/check.py input.svg
   ```
